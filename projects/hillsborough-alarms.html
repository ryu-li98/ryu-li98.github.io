Signal Controller Alarm Monitoring. One week of alarms, hour by hour.

A one-page Power BI dashboard for Hillsborough County that shows a full week of signal controller alarms: when each one became active, how long it stayed open, and when county staff cleared it. Alarms that started in an earlier week and are still open are counted too, so nothing that affects the week drops out of view.

The challenge

A signal controller alarm is a start time and, once staff clear it, an end time. A list of those records shows what happened, but not how long the county was exposed. A detector fault that is cleared in 30 minutes and one that stays open for months look the same in a list, and an alarm that started weeks ago doesn't belong to "this week" if you only filter by start date.

The team needed to see a week as a timeline: which hours had open alarms, how many overlapped, which ones dragged on, and which are still open right now. That meant measuring each alarm's overlap with every hour of the week instead of just counting records.

Under the hood. Overlap math in DAX and Power Query.

Hours of alarm activity in one heatmap cell

Each cell is a date and an hour slot. The measure keeps every alarm that overlaps the slot, clips its start and end to the slot, and adds up the overlap in hours. That is why an alarm that began months earlier still fills the hours it was open this week. Excerpt simplified for readability.

Hourly Alarm Duration (Hours) =
VAR SlotStart = SELECTEDVALUE ( 'Date Selection'[Date] )
    + DIVIDE ( SELECTEDVALUE ( 'Alarm Hour Slots'[Hour] ), 24 )
VAR SlotEnd = SlotStart + DIVIDE ( 1, 24 )
VAR TotalHours =
    SUMX (
        FILTER ( 'V2',
            'V2'[Active EST] < SlotEnd
                && 'V2'[Cleared EST (Effective)] > SlotStart ),
        VAR OverlapStart = MAX ( 'V2'[Active EST], SlotStart )
        VAR OverlapEnd =
            MIN ( 'V2'[Cleared EST (Effective)], SlotEnd )
        RETURN MAX ( 0, ( OverlapEnd - OverlapStart ) * 24 )
    )
RETURN
    ROUND ( COALESCE ( TotalHours, 0 ), 2 )

An end time for alarms that are still open

An open alarm has no cleared time, so Power Query gives it one: the current time in Eastern time. The offset switches between −4 and −5 hours on the second Sunday of March and the first Sunday of November, so the overlap math stays right all year. Each alarm is then sorted into a duration bucket.

Why it matters

An alarm that stays open is a problem that stays open. This page makes it hard to miss.

By measuring how long alarms overlap each hour instead of just counting them, the dashboard shows the county how much of the week each location spent in an alarm state, which alarms carried over from earlier weeks, and which are still waiting for staff to clear them.

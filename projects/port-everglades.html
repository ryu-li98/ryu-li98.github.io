The challenge

Port Everglades is one of the busiest cruise ports in the world, and it sits next to the Fort Lauderdale airport, the Broward County Convention Center, and the 17th Street drawbridge. Cruise arrivals and departures, convention events, and bridge openings all load the same few roads: 17th St., US-1 (Federal Hwy.), SR-84, and Eisenhower Blvd.

The information needed to understand this was spread across separate sources: probe-vehicle travel times, cruise ship schedules, bridge opening logs, convention center events, and crash records. The goal was a single monthly view showing when these events happen, how they overlap, and how the corridors perform compared with normal conditions.

My approach. From raw feeds to one view.

Under the hood. DAX and Power Query.

Rolling three-month TTI

Travel time index is average travel time divided by average free-flow travel time. This measure finds the latest date in the data and counts back to a three-month window, then calculates weekday TTI for it, so the comparison updates by itself as new data arrives.

TTI|3m|weekday =
VAR LatestDataDate =
    CALCULATE (
        MAX ( Mobility[Day] ),
        REMOVEFILTERS ( Mobility[Day] )
    )
VAR TargetMonthDate = EDATE ( LatestDataDate, -4 )
VAR PeriodStart = EOMONTH ( TargetMonthDate, -3 ) + 1
VAR PeriodEnd = EOMONTH ( TargetMonthDate, 0 )
RETURN
    CALCULATE (
        DIVIDE (
            AVERAGE ( Mobility[travel_time_minutes] ),
            AVERAGE ( Mobility[FFTT_min] )
        ),
        REMOVEFILTERS ( Mobility[Day] ),
        Mobility[Day] >= PeriodStart,
        Mobility[Day] <= PeriodEnd,
        Mobility[Weekday or Weekend] = "Weekdays"
    )

// Groups each crash into a 3-hour period for the heatmaps
let
    HourValue = Time.Hour(Time.From([Time])),
    StartHour = Number.IntegerDivide(HourValue, 3) * 3,
    EndHour = StartHour + 3,
    FormatHour = (h as number) as text =>
        if h = 0 or h = 24 then "12 AM"
        else if h = 12 then "12 PM"
        else if h > 12 then Text.From(h - 12) & " PM"
        else Text.From(h) & " AM"
in
    FormatHour(StartHour) & " - " & FormatHour(EndHour)

Why it matters

Five scattered datasets became one monthly decision tool. Built end to end by me.

Before this dashboard, answering a simple question like "did that cruise day or bridge opening slow down US-1?" meant pulling travel times, ship schedules, bridge logs, event calendars, and crash records separately and lining them up by hand, roughly 27 hours of work from start to end. I owned the whole pipeline, from pulling the data to modeling it and designing the report, so the team can now answer that question in seconds.

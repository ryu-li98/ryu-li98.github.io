SW 10th St. Mobility Improvements. A Smart Work Zone performance report.

A seven-page Power BI report for the SW 10th St. Connector project in Broward County, where new connector lanes, rebuilt I-95 interchanges, and a reconstructed NW 48th St. bridge are under construction from August 2026 through 2032. It tracks safety, travel time, turning movement counts, detour routes, and field drive tests, so the project team can compare conditions before and during construction.

The challenge

The SW 10th St. Connector project builds new connector lanes for regional traffic, reconstructs local SW 10th St. at the I-95 interchanges and Hillsborough Blvd., and rebuilds the NW 48th St. bridge. The work covers about three miles of SW 10th St., from Florida's Turnpike to Natura Blvd., and runs from early August 2026 to 2032.

A project this long needs a clear baseline. The team had to know how safe and reliable the network was before construction, watch for changes once work began, and check how drivers were affected on the NW 48th St. detour routes. That information came from probe travel times, crash records, turning movement counts, and field drive tests, each in its own format.

Turning raw GPS into drive-test runs

Each GPS file is grouped into a single run, sorted by time, and summarized. Direction is then assigned from the change in longitude between the start and end of the run, ignoring tiny GPS movements. Excerpt simplified for readability.

// Group every GPS point by run, then summarize it
Grouped = Table.Group(WithRunKey, {"Run Key"},
  {{"Run Summary", (t as table) as record =>
    let
      Sorted = Table.Sort(t, {{"timestamp",
                 Order.Ascending}}),
      StartTime = Sorted{0}[timestamp],
      EndTime = Sorted{Table.RowCount(Sorted) - 1}
                  [timestamp],
      AvgMPH = List.Average(
                 List.RemoveNulls(t[speed_mph])),
      Miles = List.Max(List.RemoveNulls(
                t[#"Cumulative Distance (mi)"]))
    in
      [Duration = EndTime - StartTime,
       #"Average Speed (mph)" = AvgMPH,
       #"Total Distance (mi)" = Miles]
  }}),

// Direction from the change in longitude (Route 3)
if Number.Abs(LongitudeChange) < 0.001 then null
else if LongitudeChange > 0 then "EB" else "WB"
